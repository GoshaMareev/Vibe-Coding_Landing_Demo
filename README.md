# Занятие №3. Замена картинок в лендинге

> Объединяем результаты занятий 1 и 2: подменяем чужие картинки в готовом лендинге на свои AI-иллюстрации.

## О чём задание

У вас уже есть:
- **Лендинг** в одном HTML-файле (с занятия 1) — со «временными» картинками из интернета (например, Unsplash)
- **Свои картинки**, сгенерированные через AI (с занятия 2)

Задача — соединить их: заменить чужие картинки на свои, не сломав сайт.

## Что вы освоите

- Структуру single-file лендинга (как в одном файле живут HTML, CSS и JS)
- Поиск по коду (`Ctrl+F`) — главный инструмент работы
- Два способа замены картинок: в CSS (`background: url(...)`) и в HTML (`<img src="...">`)
- Подготовку графики для веба (сжатие, переименование, организация папок)

## Что нужно для работы

| Что | Зачем |
|-----|-------|
| Файл лендинга (`.html`) | Тот, что делали на занятии 1 |
| 4–5 AI-картинок | Те, что генерировали на занятии 2 |
| VS Code | Бесплатный редактор — [скачать](https://code.visualstudio.com/) |
| Браузер | Любой современный (Chrome, Firefox, Edge) |
| squoosh.app или tinypng.com | Для сжатия картинок (онлайн, без установки) |

## Структура занятия

**6 шагов, ~60 минут:**

1. Создаём папку проекта со структурой `assets/`
2. Подготавливаем картинки (переименование + сжатие)
3. Открываем файл и находим все картинки через `Ctrl+F`
4. Заменяем фоновую картинку в CSS
5. Заменяем обычные картинки в HTML
6. Проверяем результат и исправляем ошибки

## Главный приём

Откройте файл лендинга, нажмите `Ctrl+F` и введите:

```
unsplash.com
```

Все места, где нужно заменить картинку, подсветятся. Поиск покажет точное число — например, «18 of 18». Это и есть полная карта вашей работы.

## Что сдавать

ZIP-архив с папкой проекта:

```
my-project/
├── index.html      ← лендинг с заменёнными картинками
└── assets/         ← все ваши картинки
    ├── hero-bg.jpg
    ├── menu-cappuccino.jpg
    └── ...
```

Плюс скриншот итогового сайта.


## Если что-то пошло не так

- **Картинка не появилась** → проверьте путь в `src` (папка, имя файла, регистр)
- **Случайно удалили кавычку** → `Ctrl+Z` (отмена)
- **В браузере всё ещё старая картинка** → `Ctrl+Shift+R` (жёсткое обновление, без кэша)
- **Не понимаете, в каком блоке находитесь** → прочтите комментарии и названия классов выше

В файле задания есть полная таблица типичных ошибок с решениями.

## Важно

Это задание — **не про написание нового кода**. Вы только редактируете готовый файл: ищете нужные строки и подменяете в них одно значение. Если что-то не получается — позовите учителя, не пытайтесь переписывать сайт.
